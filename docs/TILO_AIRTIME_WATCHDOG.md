# TILO 방송 감시 프로브

PR #240의 서버 측 송출 기록 최신성 API를 호출하는 외부 감시용 스크립트입니다.

```bash
TILO_BROADCAST_ADMIN_ID=123 \
CENTRAL_BROADCAST_WORKER_SECRET=your-secret \
node scripts/check-tilo-airtime.mjs
```

`TIMELINK_API_BASE`로 API 주소를 변경할 수 있습니다. 종료 코드 0은 최근 5분 내 송출 기록이 있음, 1은 기록 지연, 2는 비활성·권한·API·네트워크 오류입니다. 비밀키는 환경변수로만 전달하고 로그에 출력하지 않습니다.

**중요:** 송출 기록이 없는 것이 곧 송출 프로세스 중단을 증명하지는 않습니다. 권리 허가 음원이 없는 정상 정지 상태에서도 기록 지연이 나타납니다. 이 스크립트는 감시 도구이며 실제 방송 송출 프로세스, 자동 재시작, 장애 통보 서비스는 별도 구축해야 합니다. 서버가 활성화되어 있어도 이 스크립트만으로 방송이 자동 복구되지는 않습니다.
