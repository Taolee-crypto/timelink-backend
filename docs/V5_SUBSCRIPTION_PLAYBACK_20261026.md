# DAILY FREE 재생 연결 (2026-10-26)

## 동작

`MUSIC_SUBSCRIPTION_PLAYBACK_ENABLED=true`일 때만 공개 V5 음원에서 유효한 실결제 구독을 조회한다. 기본값은 비활성이다. 기존 곡 충전, 방송, DJ 모니터는 기존 경로를 유지한다. 새 플레이어는 구독 세션에 `sub_` 접두어를 사용해야 하며 오래된 플레이어에는 새로고침을 요구한다.

회원의 현지 날짜에 포함 시간을 먼저 기록하고 초과분은 1밀리초=10원장 원자(1초=1 TL)로 지갑에서 정산한다. 지갑 지급 TL, 보너스 TL, 구매 TL 순으로 소비한다. 구매 재원 70%는 창작자의 유료 정산 계정, 지급 재원 70%는 비환금성 TL_B, 나머지 30%는 회사 계정에 기록한다. 자기 곡의 합법적인 창작자 수익은 순차감액과 총 청취 과금액을 구분해 검증한다. 곡 충전 풀에는 손대지 않는다.

청취 사용량, 지갑 거래, 권리자 스냅숏, 세션 누적 체크포인트를 D1 batch로 함께 기록한다. 동일 보고 재전송은 추가 차감하지 않는다. 날짜 경계는 구간별로 커밋하므로 후속 구간 실패 후 재전송하더라도 앞선 구간이 중복 처리되지 않는다. 겹치는 회원 청취 구간과 오래된 세션 버전은 롤백한다. 잔액 부족 시 지불 가능한 구간까지만 처리하고 정지를 요청한다. 정지는 미리 예약한 TL의 환급 없이 세션을 닫는다.

## 검증의 범위와 남은 작업

클라이언트 미디어 누적 시간은 서버 경과 시간으로 제한한다. 이는 음성이 실제 들렸다는 독립적인 증명이 아니다. 지연 보고는 가장 최근의 서버 보고 구간에 귀속되므로 실제 자정 전후 청취와 미세한 차이가 날 수 있다. 운영 활성화 전에 장시간·백그라운드·일시정지·재접속의 실제 기기 검증이 필요하다.

구독료 창작자 예산 70%의 월별 배분은 **아직 실행하지 않는다**. 포함 시간은 사용량과 권리자 스냅숏을 미정산 상태로 저장한다. 월말 배분, 환불·취소 후 조정, 이상 청취 검토, 정산 보고가 완성되기 전에는 실결제 구독 재생을 켜지 않는다. TLC 채굴 지급도 이 변경에 포함되지 않는다. 구독 결제 모드와 재생 플래그는 별개이며 어떤 운영 환경 설정도 변경하지 않았다.

## 검증

- SQLite: 서버 경과 제한, 포함 시간 소진, 혼합 재원 초과 차감 및 70:30, 자기 곡, 재전송, 겹치는 동시 세션 롤백, 자정 초기화, 취소·종료, 권리자 스냅숏, 곡 풀 미사용.
- 실제 로컬 D1: 포함 시간 및 자기 곡 초과분의 원장·사용량 원자적 커밋과 재전송.
- 기존 구독 주문, 기여도, 창작자 보고와 재생 원장 회귀 검증 및 TypeScript.
