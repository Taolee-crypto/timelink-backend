## 운영 화면

- 일반 방송: `/radio.html`
- 보상 규칙: `/reward-policy.html` (관리자 인증)
- 공용 관리대장: `/v5-work-ledger.html` (관리자 인증)
- 신고 검토: `/community-admin.html` (관리자 인증)
- 차량 상세: `/car-detail.html?id=<channel_id>`
- 기존 음원 등록: `/creator.html` → 기존 음원 등록

저장소의 현재 Worker 설정은 D1을 사용하고 R2 바인딩은 없다. 새 비공개 등록·차량 사진 기능은 기존 D1 객체 저장 방식을 재사용하고, R2 바인딩이 있을 때만 R2를 쓴다. 비공개 객체 키만으로 원본 접근 권한을 부여하지 않는다.

## 검증

실행된 검증:

- TypeScript 엄격 검사, Worker 번들 dry-run.
- 실제 원장 함수를 격리 SQLite에서 실행: 결제 지급·보너스 분리·고유키 충돌·실패 전체 롤백.
- 광고 세션 시간·예산·일일 중복·완료 로그·원장 보상.
- 일반 환전 50% 조건·에스크로·수수료·신청 중복.
- 국가별 방송 허가·없는 권리·만료 권리 거절.
- 댓글·좋아요·신고·관리자 검토, 차량 소유권·공개 차량번호 제외.
- 10곡 암호화 등록·중복·11곡 거절·실패 객체 정리.
- 관리자 규칙의 버전 충돌·범위·POC 비중·감사 이력.
- 실제 회원가입 핸들러 3종의 동일 이메일 인증·정책·V5 TL_B 지급.
- **실제 로컬 workerd/D1**에서 테이블·트리거, 공용 관리대장, D1 비공개 객체 저장/읽기/삭제 왕복.

- 프런트 메뉴 18/18, 관리대장 구조·구문, 변경 HTML/JS 구문 검사.

미실시:

- 인증된 운영 계정·운영 D1/R2·실제 PG·은행·온체인 지급·24시간 오디오 E2E.
- 브라우저 시각 검수: 현재 실행 환경의 브라우저 바이너리 다운로드가 실패하여 미실시. 구문 검사를 시각 검수로 대체 표기하지 않는다.

실제 운영 성공 증거가 없는 기능은 `운영확인`으로 올리지 않는다. 원본 추적 보고서나 관리자 개인의 기존 기록을 수정 완료로 일괄 덮어쓰지 않았다.
