# 보상 기준 정리 · 2026-10-26

사용자 결정: 새로 제안한 보상 기준은 폐기하고 기존 보상 기준을 유지한다. 1초=1TL과 24개 시간 상품은 유지한다. 개인·카페는 필요한 시간 상품을 선택하고 포함 시간 초과분은 1초=1TL로 이용한다. 홈페이지 리뉴얼은 별개다.

기존 보상 기준의 실제 소스는 `src/v5-reward-policy.ts`와 DB의 `v5_reward_policy`다. 기존 지급·PoC·채굴·환전 처리는 이 정책을 읽고 있으며 이 변경에서는 값이나 잔액을 변경하지 않는다. 관리자 수동 조정과 변경 이력도 유지한다.

폐기 대상은 별도로 제안된 구매 비중 40%, 0.1~0.9 기여지수 및 등급별 신규 채굴 지수 등을 확정 보상 기준으로 도입하는 안이다. 해당 새 채굴은 지급 경로에 활성화되지 않았다. 관리 API의 새 정책 쓰기는 HTTP 410으로 거절하며, 조회는 폐기된 제안의 과거 자료임을 명시한다. 관리자는 `/api/admin/reward-policy`를 사용한다.

기존 원장·구매 영수증·검증된 사건 기록은 삭제하거나 재작성하지 않는다. 저장된 새 제안과 사건은 과거 자료로만 남으며 실제 보상 정책이라는 의미를 갖지 않는다. 24개 상품의 판매가·시간·결제 활성화 여부는 이 변경으로 바꾸지 않는다.
