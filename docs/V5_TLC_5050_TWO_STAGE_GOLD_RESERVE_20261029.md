# TILO Group TLC: 50:50 공동채굴 + 2단계 가치안정 준비금

**정책 반영 기준: 2026-10-29** / 개발 단계. 등록 법인명·가격 보장·금 보유 증거를 임의 생성하지 않는다.

## 기본 구조

- **사전 설정된 총발행 한도가 없다.** TLC는 검증된 TimeLink 이용·구매·창작 기여를 서버에서 측정하여 그때그때 새로 기록하며, 발행 사건의 *누적 총량*과 *현재 유통량*은 별도 집계한다.
- **단일 채굴 사건의 총량을 50:50 분배한다.** TLC 9자리 정수 원자 단위로 회원 50%, 틸로그룹 장기준비금 50%. 원자 나눗셈의 홀수 1원자는 준비금에 귀속된다. 회원 지갑에는 회원 몫만 들어간다. 회사 50%를 **추가 발행하지 않는다**.
- **1차 사용가치:** 회원 몫이 TimeLink 생태계에서 합법적 이용·교환에 쓰이면서 형성되는 수요와 효용. 회사 몫은 잠금 원장 `platform/tilo-group/TLC/permanent_value_reserve_locked`의 `held_atoms`에 저장, `available_atoms=0` 유지.
- **2차 준비자산:** 경영상·법률상 조건 및 시장/가격 안정성이 충분히 검증되었을 때, 운영자 승인에 따라 회사 준비금의 일부를 물리적으로 검증 가능한 금으로 **점진적으로 전환해 별도로 보유**한다. 현재 금 보유량 확인: **0g(확인된 금이 없다는 뜻이며 실제 금 보유량이 0이라는 금융실사 결과가 아님)**, 금 자동 전환: 미구현·비활성화.
- 금 준비자산은 **생태계의 위험 완충 장치**로 구상하며 모든 TLC의 1:1 금 상환·가격 하한·차익·일정 수익률을 보장하지 않는다. 실제 백업 효력은 금 매수·보관·환가성·권리 구조 및 감사에 달려 있다.

## 금 전환의 회계·유통 제약

회사가 TLC를 장외 거래처에 넘기고 금을 수령하면 **넘긴 TLC도 원칙적으로 유통될 수 있다.** 그러면 '회원 50%만 유통' 원칙을 유지하지 못한다. 이를 방지하려면 두 가지 중 하나가 필요하다.

1. 회사의 외부 현금 수익으로 금을 별도 매입하고 회사 TLC는 잠금 유지한다. 이 방식은 **TLC를 직접 금으로 교환한 것이 아니라** 회사가 현금으로 금을 추가 확보한 것이다.
2. TLC를 직접 금으로 교환하려면 결제/상대방 수령 기록과 동시에 **그 회사 TLC를 영구 소각하거나 법적·기술적으로 검증되는 장기 재유통 불가 잠금**을 실행하여 전체 유통 가능량이 임의로 증가하지 않도록 한다. 내부 원장 소각과 외부 블록체인 소각은 별개이며, 외부 발행 후에는 반드시 실제 체인 상태와 맞춰야 한다.

어느 방식을 사용할지는 **법인·세무·자산수탁·금 공급 계약·시장 상황 검증 후** 운영자가 결정해야 한다. 현재 프로덕션에는 금 거래·이체·소각 실행 API가 없으며 준비금 잠금만 작동한다. 관리자 화면은 확인된 데이터만 표시하고 '금 가치 백업 완료'라고 표시하지 않는다.

## 전환 전 필요한 승인·증빙 필드 (추후 별도 구현)

- 관리자 신청·승인자/집행자 분리·수동 승인 시각·거래별 멱등키
- 총 채굴 회계 및 그룹 잔여 TLC 원자량, 거래 대상/수량·당시 평가가격·거래상대방
- 회사 TLC의 소각 또는 재유통 불가 잠금 증빙
- **실물 금** 수탁기관·보관증명·순도·순중량(g)·일련번호·보험/감사 기록 및 실제 소유권
- 취득원가, 외부 시세, 금 보관료와 세금, 이용자 설명·감사 이력
- 환불·취소·사고 시 법적 책임, 금 전환에 대한 감독기관 승인 또는 등록 필요 여부

## 기술적 연결·검증

- `src/v5-tlc-mining-split.ts`: 채굴 원자량 분배·회사 잠금 지갑·2단계 가치 정책/현재 금 미확정 상태
- `src/economics.ts`: 서버 검증 POC → 단일 총발행량 → 회원 지갑 + 회사 잠금 지갑 + 보존 원장. 기존 채굴기록 소급 변경 없음
- `/api/admin/tlc-group-reserve`: 관리자 조회 전용 TLC 잠금 잔액·누적 발행 범위·금 준비 실사 미완료 표시
- `public/tlc-group-reserve.html`: 개인 유통분과 회사 준비금의 구분, 금 전환 준비단계 명시
- 검증: `node scripts/test-v5-economy-renewal.cjs` / `node scripts/test-v5-tlc-gold-stages.cjs`

**중요:** 총발행 최대치 없음은 무검증 무제한 채굴을 뜻하지 않는다. 일일·월간 보상 상한, 운영자 수동 정책과 이중발행 방지 장치는 유지된다. 1차 효용과 2차 금 보관은 가치안정의 목표이지, 코인 가치의 확정 보증이 아니다.
