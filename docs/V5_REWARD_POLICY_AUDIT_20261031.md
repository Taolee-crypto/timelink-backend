# TimeLink V5 보상규칙 현행 감사 및 폐기 적용 기록

기준일: 2026-10-31. 대상: 관리자 `/reward-policy.html`, `src/v5-reward-policy.ts`, `src/economics.ts`, `src/v5-ad-reward.ts`, 가입 지급 경로.

## 폐기 규칙 처리

- 광고주 전용 가입 추가 보상 `advertiser_signup_bonus`: 규칙 카탈로그에서 제거. 광고주로 등록되더라도 별도 추가 선물을 지급하지 않음. 기존 회원의 확정 보상은 취소하지 않음.
- 신규 광고 보상 `ad_min`, `ad_max`, `ad_default`: 규칙 삭제. `/api/eco/ad-session`, `/api/eco/ad-reward`는 HTTP 410으로 신규 지급 차단. `wallet_ad`와 과거 전표·감사 자료는 보존.
- 폐기된 악보 서비스의 `score_cap`, `score_share`, `score_use`, `score_view`, `weight_score`: 규칙 삭제. 레거시 PoC 계산에서 악보 점수/조회 제거. 4가지 현재 영역의 기본 가중치는 재생 40%, 유료 TL 소비 30%, 청취 20%, 업로드 10%.
- 이전에 DB에 저장된 폐기 규칙값은 **읽기 시 제외**하고 역사적 정책 JSON 및 변경 이력은 보존. 레거시 5요소 PoC 설정의 살아 있는 4요소는 기존 비율을 보존하도록 재정규화하며, 알 수 없는 임의 설정키는 거부. 실제 기존 사용자 지급분은 소급 재산정하지 않음.
- DJ 및 영업매니저 신규 계약·배정·방송 과금은 폐기 API에서 410 반환. `src/sales-managers.ts`의 신규 수익 정산 진입점은 직접 호출 시에도 종료 오류로 차단. `src/routes/dj-cafe.ts`는 역사 조회만 유지하고 쓰기 요청을 종료하며 과거 직접 TL_B를 더하던 `grantBonus`도 무지급으로 변경. 인카 DJ 채널 홍보 수익 배분 종료. 기발생 계약과 원장은 보존하고 과거 정산 채무는 관리자 회계 심사로 별도 처리.

## 통과 조건 (코드 및 테스트)

- 폐기된 항목이 관리자 편집 정의에 없어야 함.
- 구버전 DB 설정으로 관리자 규칙 조회가 실패하지 않아야 함.
- 광고 보상 API가 신규 지급을 만들지 않아야 함.
- 악보 조회/사용/공유가 PoC 신규 계산에 참여하지 않아야 함.
- 가중치 합계 1, 부정확하거나 알 수 없는 저장 키는 거부, 관리자는 수동 버전 관리.

## 추가 검증에서 발견된 **미해결** 경제 규칙 위험

1. **개선:** `src/economics.ts`의 오래된 `/api/eco/consume` 경로가 TL_B 소비 창작자 보상을 TL_A에 넣던 오류는 TL_B 원천으로 수정. 다만 해당 레거시 엔드포인트는 클라이언트가 보고한 사용 초·금액을 받아 처리하고 V5 이중분개 원장에 완전히 연결되지 않아, 실제 공개 서비스 호출이 남아 있는지 확인하고 검증된 재생 증빙·정산 경로로 통합해야 한다. 이 문제는 **운영 적합성 미검증**이다.
2. **개선:** `src/v5-cashout.ts` 일반 환전의 구매 50% 기준에 더해 실제 `live` 결제 구매 lot의 지갑 잔여분을 사용하도록 원장 출처 대사·동시 지갑 버전 검증을 추가했다. 시험/미확인 구매, 권리분쟁, 법적 만기 승인이 끝난 구매분, 창작자 수익을 일반 구매원금으로 오인하지 않는다. TL_P→TL_B 전환은 이미 별도 법률 심사·승인된 lot에만 가능한 경로로 존재하며 이 PR은 자동 전환 플래그를 활성화하지 않는다. 구매 50% 조건 및 법적 환불·환전의 구체적 약관 적합성은 별도 심사 대상.
3. `src/economics.ts`의 기존 V5 채굴 산식(월 TL_P 소비 × 0.08 × PoC × 플랜B 배율)은 운영자가 유지하기로 한 **기존 보상 규칙**이다. 2026-10-26의 TL-1~24 상품별 새 기여·채굴안은 역사적 초안이며 동시 지급에 사용하지 않는다. 이 구분이 실제 전송·발행 호출과 관리자 화면에도 일관되는지는 별도 운영 검증이 필요하다.
4. 관리자 환전 수수료·가입 보너스·충전 보너스는 유지되지만 지급 준비금, 현금 정산대장, 환불 역분개, 실운영 교차검증은 이 변경만으로 완료되지 않음.
5. TILO의 실제 방송 초 × 0.3 TL × 권리자 70%/플랫폼 30%는 별도 원장과 계약 검증이 필요하며 광고/악보 폐기와 독립.
6. 추천 TL_B 및 POC는 검증 후 보상 규칙을 유지. 환불 역분개·자기추천 방지 및 다계정 검증은 별도 유지.
7. **개선:** 레거시 PoC에서 단순 MP3 원본 업로드 가중치와 관련 관리자 규칙을 제거했다. TL3 공유·검증된 작품의 정확한 승인 기준, 허위 업로드/자기 재생 제외, 실제 증빙 생산자 연결은 추가 운영 검증이 필요하다.

**판정:** 폐기 기능의 신규 광고·DJ·영업매니저 보상, 악보·MP3 원본 점수 및 일반 환전의 구매 출처 보호는 코드 경로에서 수정했다. 단, 전체 경제 규정의 실운영 적합성은 **미검증**이다. 본 PR 병합과 배포 전/후 자동화·DB 경로 검증, 운영 데이터 기반 승인 필요. 폐기 이전 발생 금액과 장부 이력 삭제 금지.
