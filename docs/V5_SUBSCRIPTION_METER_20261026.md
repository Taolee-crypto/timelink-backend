# V5 일일 포함시간·초과 과금 계량 코어

2026-10-26 · 경제 리뉴얼 후속 구현

## 이번에 구현한 범위

- 실운영 구독 자격과 해당 국가 시간대의 일일 사용량 조회.
- 매일 포함시간을 먼저 사용하고, 초과분은 실제 1초당 1TL로 계산.
- TL 정밀도 10,000 atoms/TL에서 1ms 초과 사용은 정확히 10 atoms. 재생 보고 주기에 따라 과금액이 달라지지 않는다.
- 사용 기록과 원장 차감의 원자적 확정을 위한 서버 내부 SQL 계획 생성.
- 동일 구간 재전송의 멱등성, 다른 세션의 겹치는 시간대 차단, 일일 사용량 버전 비교.
- 구독 취소·변경을 확정 직전에 재확인. 여러 활성 구독이 겹치면 임의 선택하지 않고 중단.
- 현지 자정과 구독 만료를 넘는 구간은 먼저 분할하도록 요구.
- 서머타임으로 현지 하루가 25시간인 경우도 처리. TL-24는 실제 24시간을 포함하고 추가 1시간은 초과분이다.

## 코드와 저장소

- `src/v5-subscription-meter.ts`
- `v5_music_entitlements`: 유효 구독·등급·시간대·기간·원천 결제·실운영/시험 구분.
- `v5_music_daily_usage`: 회원·현지 날짜별 포함·초과 사용량과 버전.
- `v5_music_usage_events`: 곡·세션·검증 구간·포함/초과량·과금액·자격 연결.
- `GET /api/eco/daily-free-allowance`: 로그인한 본인의 현재 자격과 일일 포함 잔여시간. 자격이 없으면 active=false.

구독 생성·판매·결제 활성화 경로는 이번 변경에 포함하지 않는다. 자격은 향후 서버에서 검증된 구독 결제 처리만 생성해야 하며, 이 모듈에는 사용자가 자격을 직접 만드는 HTTP 경로가 없다. 시험결제 자격은 실운영 청취 자격으로 선택하지 않는다.

## 원장 연결 규약

`prepareDailyMusicUsage`는 서버가 검증한 실제 재생 구간만 받는다. 브라우저가 임의로 보낸 시간·회원·자격을 그대로 전달하지 않는다. 기존 재생 라우트는 아직 이 함수로 전환하지 않았다.

1. 구독 자격, 현지 날짜, 사용량 버전, 중복 이벤트를 읽는다.
2. 포함시간과 초과량을 계산한다. TL-1의 첫 1시간은 포함, 이후 10분은 600TL.
3. 이미 확정한 동일 usageKey이면 재처리 결과를 반환하고 새 SQL을 만들지 않는다. 같은 키로 다른 회원·곡·구간을 보내면 충돌이다.
4. 초과량이 없으면 계획 SQL만 D1 batch로 확정할 수 있다.
5. 초과량이 있으면 V5 원장 초과 과금과 계획 SQL을 같은 `postLedgerTransaction`의 atomicStatements로 처리한다.

초과 원장 거래는 다음을 만족해야 한다.

| 필드 | 값 |
| --- | --- |
| idempotencyKey | daily-free-overage:{usageKey} |
| transactionType | daily_free_overage |
| source | verified_subscription_playback |
| actorUserId | 실제 사용 회원 |
| referenceType | music_usage |
| referenceId | usageKey |
| metadata.overage_atoms | 정확한 초과 차감 atoms |

계획 SQL은 실제 posted 거래, 회원 본인 지갑 차감 합계, 정확한 금액 및 원장 균형을 검사한다. 초과 원장 없이 사용량만 확정하려 하면 전체 묶음이 실패한다. 원장 차감 후 사용량 버전 충돌이나 구독 취소가 확인되어도 전체 묶음이 취소된다.

유료 TL과 보상 TL의 차감 순서·창작자 재원별 70:30 배분은 기존 재원 규칙을 따라 상위 정산 서비스에서 구성한다. 계량 코어는 지갑 잔액·창작자 수익·TLC를 직접 발행하지 않는다.

## 남은 연결

- 구독 주문·실결제 검증·기간/환불 정책 및 자격 생성.
- 서버에서 검증된 실제 재생 구간의 현지 날짜·만료 경계 분할.
- 기존 플레이어의 곡 충전·선차감 경로와 구독 포함시간 경로 전환.
- 재원별 초과 과금 원장과 창작자 지분 정산 연결.
- 구독 포함시간의 권리자 정산 재원·70% 배분·미청취/환불 처리.
- 사용자 화면의 잔여시간·초과 과금 동의·잔액 부족 안내.

## 검증

`scripts/test-v5-subscription-meter.cjs`는 실제 SQLite에서 포함시간, 600TL 초과 과금, 원장·사용량 동시 롤백, 멱등 재처리, 다른 곡으로 키 재사용, 동시 버전 충돌, 구간 겹침, 다음 날 초기화, 취소, 시험 자격 제외, 25시간 서머타임 날짜를 확인한다. 실제 D1 런타임의 스키마와 빈 자격 조회도 기존 D1 회귀 검증에 추가한다.
