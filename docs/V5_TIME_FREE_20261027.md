# TIME FREE 시간 이용권

2026-10-27 사용자 확정: 1시간 구매는 3,600초의 TIME FREE 음악 청취권이다. 곡별 TL 충전과 분리하며 공개된 재생 가능 곡을 바꿔 들어도 같은 잔여시간을 사용한다. 시간 구매를 TL_B 지급으로 처리하던 종전 화면 설명을 폐기한다.

재생 사전 검사와 V5 복호화 라이선스 모두 이용권을 먼저 확인한다. 지갑 TL이나 곡별 TL이 0이어도 청취할 수 있다. 일시정지·버퍼링·탐색 이동은 사용시간에 포함하지 않는다. 클라이언트가 보고한 실제 재생시간은 서버 경과시간과 이용권 잔여시간으로 제한한다. 소진되면 재생을 멈추며 같은 세션에서 TL 과금으로 자동 전환하지 않는다.

이용권 청취에는 TL 차감·TL 보상·TLC 발행·곡별 TL 배분을 실행하지 않는다. 기존 관리자 보상 정책의 청취 기여 가중치와 상한을 사용해 poc_logs 및 사용자의 기여지수만 반영한다. 이용권 사용량과 기여 기록은 같은 DB 트랜잭션에서 확정한다. 중복 보고·중복 구매 완료 요청·동시 세션은 중복 시간이나 기여를 만들지 않는다.

현재 SharePlace 결제 경로는 테스트 모드다. 완료한 테스트 구매는 테스트 TIME FREE 청취 이용권으로 연결한다. 기존 test_paid/toss_paid 기록도 사용자 본인에게 한 번만 복구하며 기존 지갑은 변경하지 않는다. quoted/pending_toss는 이용권을 만들지 않는다. 실제 현금 결제 전환이나 실결제 가격·환산율은 변경하지 않는다. 기존 정기 구독과 곡별 TL 과금 경로는 유지한다.

검증: 실제 Worker HTTP 사전 검사에서 지갑·곡별 원장 테이블 없이 다른 두 공개 V5 곡의 재생 허용, 비공개 곡 거절, SQLite 원자성·3,600초 상한·중복·일시정지·탐색 상한·동시 세션·복수 이용권·기존 구매 복구·기여 증가·TL 원장 미생성. TypeScript 전체 검사 및 기존 구독 과금 회귀 검사를 함께 실행한다.
