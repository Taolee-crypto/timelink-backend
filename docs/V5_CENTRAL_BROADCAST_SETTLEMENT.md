# V5 중앙방송국 0.3 가중 정산 규칙

상태: 승인된 사업 규칙. 코드 반영은 정산 이벤트 연동과 별도 검증 후 활성화한다.

- 중앙방송국이 공유플레이스의 적법하게 사용 허락된 TL3 곡을 송출할 때만 적용한다.
- 실제 송출된 곡의 유효 오디오 시간(초)을 기준으로 한다. TILO 멘트, 뉴스, 중단, 버퍼, 미송출 시간은 제외한다.
- 방송 인정 TL = 실제 송출 초 × 0.3 TL/초.
- 창작자 배분 = 방송 인정 TL × 0.7.
- 플랫폼 배분 = 방송 인정 TL × 0.3.
- 청취자 수로 중복 곱하지 않고 한 방송 송출 이벤트에 한 번만 계산한다.
- 곡별 이벤트 ID로 중복 정산을 방지하고, 원장에는 정밀한 최소 단위로 기록한다.
- 관리자 콘솔에서 가중치, 분배율, 지급 상한 및 정산 재원 정책을 변경하고 변경 이력을 남긴다.
- 방송 재원 부족 시 무제한 TL 발행 금지. 정산 보류/미지급 부채 처리 정책을 먼저 확정한다.
- 기존 TRACK의 V5 개별 재생 차감/7:3 분배와 독립적인 거래 유형으로 취급한다.
- 방송 권리 동의 및 법정 권리 처리 여부를 검증한 곡만 편성한다.
- 운영 중 자동 지급 활성화 전 D1 마이그레이션, 관리자 설정, 이벤트 멱등성, 원장 균형, 테스트를 완료해야 한다.
