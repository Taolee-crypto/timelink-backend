# TimeLink V5 플랫폼 중간 검산 — 2026-10-23

## 범위와 기준
main 브랜치의 `src/economy-ledger.ts`, `src/economics.ts`, `src/p2p-tl-settlement.ts`, `src/index.ts`, 프런트엔드 `public/tl-tlc-pool.html`을 정적 점검했다. **CI/D1 실제 실행 테스트 또는 운영 환경 거래 테스트는 수행하지 않았다.** V5가 유일한 TL 원장이다.

## 확인된 차단 항목 (실거래 활성화 금지)
1. **P0 TLC 채굴:** `src/economics.ts` `/mine-tlc`은 클라이언트 제공 `tlc_amount`를 받아 지급량 결정에 사용한다. 일별 누적 조회→잔액 증가→이력 INSERT가 별도 작업이며 동시성 및 중간 실패에 취약하다. 새 정책(검증된 TL_A/TL_B 보상 출처, POC 적격성, 관리자 전환율, 중복 발행 방지)이 아직 구현되지 않았다. 우선 운영 중인 API 사용 여부를 확인하고, 관리자 제어 아래 신규 발행을 중단할 안전한 전환 계획을 수립한다.
2. **P0 P2P 검증:** `src/p2p-tl-settlement.ts`의 승인/온체인 입금/정산 허가 조건은 호출자가 공급한 불리언이다. DB에 저장된 양측 서명 승인, 주문 조건 해시, TLC Jetton 계약 및 입금 finality와 대조하는 상태 머신이 없다. 실제 거래용 HTTP API도 없다.
3. **P0 에스크로:** 현재 TL 이체 함수는 송신자의 사용 가능 잔액에서 수신자의 사용 가능 잔액으로 직접 이전한다. 주문 생성 시 TL을 잠그고 취소·만료·분쟁·정산 실패를 처리하는 V5 escrow hold/release/capture는 미구현이다. TON 온체인과 D1 간 원자적 커밋은 불가능하므로 보상 트랜잭션과 재시도/복구가 필요하다.
4. **P0 거래 UI:** 프런트엔드 주문 등록, 양측 승인, 정산 버튼이 비활성화되어 있고 상대방 계정 및 TON 지갑 소유권이 확인되지 않는다. 화면은 미리보기다.
5. **P1 원장 보존:** `postLedgerTransaction`은 균형 및 멱등성 검사를 제공하지만 일반 UPDATE는 잔액 부족을 직접 막지 않는다. P2P 함수는 별도 SQL 조건문으로 잔액을 확인한다. 이 검사는 D1에서 실제 실패/롤백하는지 동시성 테스트가 필요하다. 자산 출처 TL_P/TL_A/TL_B와 TL_B 환불 출처를 구분해 자격 세탁을 방지해야 한다.

## 불변식
- 공식 전환: TL→TLC만 허용. 회사가 TLC를 회수해 신규 TL을 발행하지 않는다.
- P2P: 이용자 보유 TL↔TLC 양방향 교환. TL 총량과 TLC 총량은 거래로 증가하지 않는다.
- 양측 회원 인증·TON 지갑 소유 증명·동일 주문 조건 서명·에스크로 확보·최종 승인 전에는 지급 불가.
- 중복 주문/콜백/재시도는 단일 거래 결과. 잔액 음수 금지, 실패 시 이중 지급 금지.
- V5 4자리 TL atom 정밀도 보존, 출처별 버킷 보존, 70:30 재생 정산 영향 없음.
- 관리자 정책 미설정 시 신규 TLC 발행 및 실거래는 비활성.

## 순차 검산 게이트
A. TLC 채굴 중복 발행 차단 및 관리자 kill switch / 회귀 테스트.
B. V5 TL 출처별 잠금·해제·최종 이전 / 잔액 부족·동시 요청·멱등 테스트.
C. TON TLC Jetton 주소·소유권·입금 finality 검증 / 위조·재사용 방지 테스트.
D. 양측 거래 조건/수령 승인 서명과 주문 상태 머신 / 취소·만료·분쟁 테스트.
E. 원장↔TON 정산 재시도/복구, 수수료 별도 회계, 대사 리포트.
F. 프런트엔드 실제 상태 연동, 다국어·모바일·접근성, 보안 점검.
G. TL3 V5 creator→shareplace→track 재생, 1초 1TL, 일시정지/중단 정산, 70:30, 지갑 표시 회귀.
H. 관리자 콘솔 수동 정책/변경 이력/권한, CI 빌드·D1 로컬/원격 마이그레이션 테스트.

**결론:** 현재 P2P UI와 TL 이체 프리미티브는 준비 단계다. 실거래 가능 판정 불가. 단계별 테스트 결과가 나올 때까지 자산 이동 기능을 비활성화한다.
