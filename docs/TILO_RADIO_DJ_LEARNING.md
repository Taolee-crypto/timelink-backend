# TILO V5 — 라디오 연계 전문 DJ 학습

## 현재 연결 후보
SBS PowerFM, MBC FM4U, KBS Cool FM, 마포FM. 공식 청취 사이트만 등록했습니다.
모든 소스의 초기 상태는 `candidate`이며 허가된 이용 범위는 비어 있습니다.
따라서 **녹음·전사·분석·학습·목소리 복제는 아직 실행할 수 없습니다.**

## 학습 처리 단계
1. 방송사 또는 권리자에게 방송 자료 이용 범위와 상업적 AI 학습 허락을 받습니다.
2. 관리자 승인 시 소스의 status, licenseReference, authorizedUses, 만료일을 기록합니다.
3. 허가된 사용 범위에 한해 방송 자료를 수집합니다. 각 처리 단계에서 canUseTiloRadioSource를 검사합니다.
4. DJ 오프닝, 곡 소개, 전환 멘트, 뉴스/날씨 대응, 멘트 길이, 속도와 분위기를 구조화합니다.
5. 검증된 진행 패턴만 TILO에 반영합니다. 음성 복제는 별도 명시적 허락이 있을 때만 가능합니다.

## 방송 보호
학습 엔진은 TL3 V5 재생과 TL 경제원장에 관여하지 않습니다. 학습 실패는 방송을 중단시키지 않습니다.
실제 수집기·D1 저장·학습 모델 연동은 별도 구현 및 권리 검증이 필요합니다.
